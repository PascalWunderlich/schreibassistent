# Begriffe
- Arbeits-Vault: Ordner einer Arbeit mit Arbeit/, Notizen/, Wissen/, System/.
- Citekey: Schlüssel einer Quelle aus Better BibTeX (z. B. mueller2024); verbindet
  Zotero, Quellenseite und `@mueller2024` im Text.
- Wegweiser: KI-Quellenseite, zeigt interessante Stellen mit Seite; kein Beleg.
- Regelprofil: Formvorgaben als YAML; Klassen maschinell, vorlage, urteil.
- Feste Prüfung: Prüfung ohne KI gegen Klasse maschinell/vorlage.
- KI-Prüfung: Prüfung auf Nachfrage, liefert Hinweis + Originalstelle.
- Ingest: neue Quelle extrahieren, indexieren, Quellenseite erzeugen.
- Seiteneditor (A): echte Typst-Seite, aktiver Absatz als Quelltext.
- Vorschau-Editor (B): Quelltext links/oben, Vorschau mit Sprung zur Stelle.
