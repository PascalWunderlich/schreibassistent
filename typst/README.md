# typst/

- `fhdw-arbeit/` – Typst-Paket mit der Vorlage nach FHDW-Vorgaben (P1), abgeleitet von
  clean-dhbw (MIT, Lizenzhinweis in `fhdw-arbeit/LICENSE`). Anleitung: `fhdw-arbeit/README.md`.
- `installieren.sh` – verlinkt das Paket als `@local/fhdw-arbeit:<version>`, damit jede
  Arbeit es mit `#import "@local/fhdw-arbeit:0.1.0": *` nutzen kann.
